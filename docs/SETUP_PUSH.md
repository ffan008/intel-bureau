# 推送通道配置指南

日报可以同时推到多个地方，单个通道失败不影响其它通道。每个通道都会：
- 自动按平台的长度限制分段；
- 网络失败时最多重试 2 次（间隔 1 秒、2 秒）；
- 同一份报告不会重复发送：如果中途失败，再次投递时只补发没发出去的部分。

## 推荐组合

| 用途 | 通道 |
|---|---|
| 在飞书里看完整排版 | **飞书应用机器人私聊**（或飞书群 Webhook） |
| 在微信里收到提醒 | **Server酱** 或 **PushPlus**（二选一） |
| 在 QQ 里收到 | **QQ 小号私聊主号**（NapCat） |
| 留档 | 本地归档（始终开启）+ 可选邮箱 |

## 各通道怎么拿 key、有什么限制

### 1. 飞书群机器人（Webhook）

1. 飞书群 → 群设置 →「群机器人」→「添加机器人」→「自定义机器人」。
2. 安全设置选「签名校验」，复制**签名密钥**；复制 **Webhook 地址**。
3. 工作台填「Webhook 地址」和「签名密钥」。

限制：每条请求不超过 20 KB；每个机器人每分钟 100 次、每秒 5 次。超长报告会拆成多张卡片。
如果安全设置用的是「自定义关键词」，请加入关键词「情报局」。

### 2. 飞书应用机器人（lark-cli）

见 [SETUP_FEISHU.md](SETUP_FEISHU.md) 第五节。填你的 open_id（`ou_…`）或群 ID（`oc_…`）。
机器人要在目标群里，或者你在应用的可用范围内。

### 3. 企业微信群机器人

1. 企业微信群 → 右上角「…」→「消息推送」（群机器人）→ 添加，复制 Webhook 地址。
2. 工作台填 Webhook 地址（只填 `key=` 后面那串也可以），消息格式保持 `markdown_v2`。

限制：每条 markdown 不超过 4096 字节（约 1300 个汉字），超出会自动分段；每分钟最多 20 条。
消息发到企业微信群里，需要在企业微信（手机或电脑）里查看。

### 4. Server酱

1. 打开 https://sct.ftqq.com ，微信扫码登录，在「SendKey」页复制（`SCT` 开头）。
   如果用的是 Server酱³ App（https://sc3.ft07.com），SendKey 以 `sctp` 开头，工作台会自动识别地址。
2. 工作台填 SendKey。

限制：Turbo 免费版**每天 5 条**（会员每天 1000 条），每分钟最多 50 条；标题不能有换行。
日报一般 1 条就够；报告特别长被拆成多条时会多占额度。

### 5. PushPlus（推送加）

1. 打开 https://www.pushplus.plus ，微信扫码登录，**完成实名认证**（未实名无法调用发送接口）。
2. 在「一对一推送」页复制 token。
3. 工作台填 token。发送渠道默认「微信公众号」；想推到群组，填「群组编码」。

限制：实名用户每天 200 次（微信渠道），1 分钟 5 次；标题 100 字、内容 2 万字；
**相同内容 1 小时内最多 3 条**。返回「请求成功」只表示已受理，最终结果可在 PushPlus 官网用流水号查询。

### 6. WxPusher

最简单的用法是「极简推送（SPT）」：

1. 打开 https://wxpusher.zjiecode.com/docs/ ，扫描「获取 SPT」二维码，得到 `SPT_…`。
2. 工作台推送方式选「极简推送」，填 SPT（多个用逗号分隔，最多 10 个）。

想推给多人、管理订阅者时用「标准推送」：在 https://wxpusher.zjiecode.com/admin/ 创建应用拿 `appToken`，
再填接收人的 UID 或 Topic ID。

限制：单条内容不超过 40000 字且不超过 65535 字节；摘要 100 字以内。

### 7. QQ（NapCat 小号私聊主号）

见 [SETUP_QQ.md](SETUP_QQ.md) 第七节。小号和主号必须互为好友。
每段不超过 1500 字，最多 6 段，段间隔 1.5 秒；超出部分在最后一段提示去工作台查看。

### 8. 邮箱（SMTP）

以 QQ 邮箱为例：

1. 网页版 QQ 邮箱 → 设置 → 账号与安全 → 安全设置 → 开启「SMTP 服务」，按提示生成**授权码**。
2. 工作台填：
   | 项目 | 填写 |
   |---|---|
   | SMTP 服务器 / 端口 / 加密 | `smtp.qq.com` / `465` / SSL（默认值） |
   | 邮箱账号 | 你的 QQ 邮箱地址 |
   | 授权码 | 第 1 步的授权码（**不是 QQ 密码**） |
   | 收件人 | 可以填多个，用逗号分隔 |
3. 正文是推送精简版的 HTML，附件是完整版 `.md` 报告。

其它邮箱：在邮箱设置里找「SMTP 服务器」和「授权码 / 应用专用密码」，465 端口选 SSL，587 端口选 STARTTLS。

## 常见问题

| 现象 | 处理 |
|---|---|
| 测试显示「该报告已投递过，本次跳过重复发送」 | 正常：同一份报告不会重复推送。点「发送测试」每次都会真的发 |
| 部分段发送失败 | 再次投递这份报告时，只补发失败的那几段 |
| 详情里出现「密钥」「token」相关错误 | 重新复制 key，注意不要多复制空格 |
| Server酱 返回 429 | 你的 IP 24 小时内调用超限，停 24 小时后自动恢复 |
| PushPlus 返回 900 | 当天请求太多被限制，今天不要再重试 |

密钥只保存在本机 `config\secrets.yaml`，工作台界面里只显示末 4 位。
