# 微信接入指南

工作台只**读取**你电脑上 PC 微信的本地聊天记录，不登录、不发消息、不改动微信。有三种接法：

| 方式 | 适合谁 | 实时性 |
|---|---|---|
| **WeChatDataAnalysis（推荐）** | 大多数人 | 开启实时模式后，每次定时任务都能读到最新消息 |
| WeFlow | 已经在用 WeFlow、并且自己有解密组件的人 | 同上 |
| 导入聊天记录文件 | 不想装任何工具，或只偶尔分析一次 | 手动导出，非实时 |

---

## 一、安装 WeChatDataAnalysis（WDA）

> **分享包用户**：安装程序已经随包带好，**不用运行下面的下载命令**。直接双击根目录的「安装接入工具.bat」，选 1 即可。下面的命令只在你想联网更新到最新版时才需要。

1. 在项目根目录打开 PowerShell，运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\tools\get-wechat-data-analysis.ps1
   ```
   脚本会从 GitHub 下载最新的 Windows 安装包，并核对官方给出的 SHA-256，保存到
   `third_party\tools\wda\`。**脚本不会自动安装**。
2. 打开 `third_party\tools\wda\`，双击 `WeChatDataAnalysis-<版本>-Setup.exe`，按提示安装。
   Windows 可能弹出「已保护你的电脑」，确认是刚下载的文件后点「更多信息 → 仍要运行」。

> 也可以从源码运行（需要会用 uv）：见 `third_party\refs\WeChatDataAnalysis\README.md` 的「源码运行」一节，
> 启动命令是 `uv run main.py`，同样监听 `http://127.0.0.1:10392`。

## 二、登录微信

1. 打开 PC 微信（4.x 版本），正常扫码登录。
2. 之后整个使用过程中保持微信登录状态。

## 三、获取密钥并解密

1. 打开 WeChatDataAnalysis。
2. 按首页向导操作：先「获取密钥」，再「解密数据库」。这一步只处理你自己电脑上的数据。
   不同版本的按钮名称可能略有差别，以 WDA 界面为准。
3. 完成后，在 WDA 里能看到会话列表，就说明成功了。

> **macOS 用户**：不要用上面的 Windows 安装包。到 WDA 的发布页下载 `WeChatDataAnalysis-<版本>-mac-arm64.dmg`
> （原生 Apple Silicon 程序，Intel 机器找 x64 版），拖进「应用程序」后正常打开，后续步骤基本一致。
> 唯一的差别是 Mac 版走「观察官方微信释放的认证材料」来拿密钥，不需要 Windows 那套内存读取。

## 四、开启实时模式

1. 在 WDA 里打开「实时模式」（也叫「实时更新」）。
2. 开启后，工作台每次拉取都会直接读微信的最新数据，**不需要每天重新导出**。
3. 如果没开实时，工作台会读取 WDA 解密出的快照，只能看到上次解密时的消息。

## 五、在工作台里选择适配器并测试

1. 打开工作台（http://127.0.0.1:8765），进入「情报源」页。
2. 在「微信」一栏，适配器选 **WeChatDataAnalysis 本地 API**。
3. 设置项：
   | 项目 | 怎么填 |
   |---|---|
   | WDA 地址 | 保持默认 `http://127.0.0.1:10392` |
   | API Token | **留空**。WDA 2.x 给本地接口加了鉴权，同一台机器上程序会自动从 WDA 的运行配置里读；跨机器部署时才需要手填（在 WDA「设置 → 接口与 MCP」里复制） |
   | 微信账号 | 留空（自动使用 WDA 里的默认账号）；登录了多个微信号时再填 |
   | 数据来源 | 保持「自动」 |
   | 拉取前先同步到解密快照 | 一般不勾。只有数据来源选了「只读解密快照」才需要 |
4. 点「测试」。看到「已连接 WeChatDataAnalysis，账号 xxx，实时读取可用」就可以了。
5. 点「刷新群列表」，把要监控的群加入白名单。**只有白名单里的群会被读取。**

测试结果对照：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 连不上 WeChatDataAnalysis | WDA 没开，或端口不是 10392 | 打开 WDA，再点测试 |
| 还没有可用账号 | 还没获取密钥、解密 | 回到第三步 |
| 实时读取不可用，将读取解密快照 | 没开实时模式 | 回到第四步 |
| 设置里的账号不在 WDA 账号列表中 | 「微信账号」填错了 | 清空这一项 |
| 要求有效的 API Token（HTTP 401） | WDA 2.x / 高级版开了接口鉴权，没读到 Token | 「API Token」留空（同机自动读）；跨机器时手填 WDA「设置 → 接口与 MCP」里的值 |
| 设置里的 API Token 无效或已更换 | 手填的 Token 过期了（WDA 重装或重置会换） | 重新复制，或清空让程序自动读 |

## 六、安全提醒（请务必读）

- WDA 2.x 的本地接口有 API Token，但它就明文存在 `runtime_settings.json` 里、本机任何程序都读得到；
  更早的版本和源码版则**完全没有密码**，还允许任何网页跨域访问（CORS 为 `*`）。
  这意味着：WDA 运行期间，你在浏览器里打开的任何网页，理论上都能读到你的聊天记录。
- 所以：**WDA 运行时不要打开不可信的网页；不用的时候关掉 WDA。**
  比较稳妥的做法是只在定时任务前后开着 WDA。
- WDA 会上报不含聊天内容的使用事件（如打开应用、打开消息页）。
- 解密出的数据库在 WDA 自己的目录里，包含全部聊天记录，不要分享给别人。

## 七、备选方案

### 方案 B：WeFlow

WeFlow 官方说明它**不再内置读取/解密组件**，需要你自己提供解密组件（来源无法校验，风险自负）。
如果你已经在用：

1. 在 WeFlow 设置里完成数据库连接，并开启「API 服务」（默认端口 5031）。
2. 复制设置页里的 API Token。
3. 工作台「情报源」→ 微信 → 适配器选 **WeFlow HTTP API**，填入 Token，拉取方式保持「ChatLab Pull」，点「测试」。

### 方案 C：导入聊天记录文件

不装任何工具也能用：

1. 准备聊天记录，支持这些格式：
   - WeChatDataAnalysis 导出的 JSON（或整个导出 zip）
   - WeFlow 导出的 JSON、ChatLab 格式 JSON / JSONL
   - CSV（表头含「时间」「发送者」「内容」，英文 time / sender / content 也行）
   - 从微信复制出来的文字，每条消息是三行：
     ```
     🐯小象
     2026年10月25日 18:14
     以后每日风向标就发飞书了……
     ```
     时间也可以写成 `2026-10-25 18:14:05`、`10-25 18:14`，或只写 `18:14`（日期按上下文推断）。
2. 二选一：
   - 在工作台「情报源」页的导入区拖入文件，或直接粘贴文字；
   - 或者把文件放进 `data\inbox\wechat\`，适配器选「导入聊天记录文件」，定时任务会自动读取。
     文件名会被当作群名（例如 `AI 创作群.txt`）。
3. 同一个文件重复导入不会产生重复消息。处理进度记在 `data\inbox\wechat\.processed.json`，
   想重新导入时删掉它即可。
