# 作战大屏 · 视觉与交互规格 v1

风格名：**深空指挥舱 / Cyber Intel Deck**。参考近来流行的「AI Agent 作战大屏」：深色宇宙背景、霓虹描边的 HUD 面板、雷达扫描、星图连线、数据流光束、打字机终端、Agent 编队卡片、Token 计量器。要求高级、克制、信息密度高：特效服务于数据，不遮挡数据。

- 数字一律等宽字体并加 `font-variant-numeric: tabular-nums`。

## 2. 背景层（固定在最底层）

1. 渐变：径向渐变 `#0a1a3a → --bg-0`，中心略偏上。
2. Canvas 星点和粒子：约 120 颗。缓慢漂移，距离近的粒子之间连淡青色细线。帧率限制在 30fps；页面隐藏时暂停。
3. 透视网格地板：底部 30% 区域放一个 CSS 3D 网格，缓慢向前滚动，`transform: rotateX(60deg)`。
4. 扫描线和噪点：极淡的横向扫描线覆盖层（透明度约 0.04），再加暗角。

## 3. 面板（HUD 框）`<HudPanel title code>`

- 背景用 `--panel` 加 `backdrop-filter: blur(10px)`，1px `--line` 描边。四个角各有 L 形亮角，长 14px、2px 宽、`--cyan`。
- 标题栏：左侧一个 6px 发光方块，中文标题（14px，`--text-0`）后面跟英文代号（`--font-display`，10px，`--text-2`，字距 2px）；右侧放可选的状态点或操作。
- 边框上有一段约 80px 长的亮光，沿边框匀速流动（`conic-gradient` 配合 mask，或 SVG `stroke-dashoffset`），周期 6s。
- 面板依次入场：从下方 12px 处淡入，每个面板延迟 60ms。

## 4. 大屏布局（固定 1920×1080 画布，按窗口等比缩放并居中）

```
┌ 顶栏 72px：◤ 情报局 · INTEL BUREAU ◢（故障风标题）｜模式 LIVE/DEMO｜三平台连接灯｜时钟 + 下次运行倒计时｜[▶ 立即出报]
├ 左 440px ───────────┬ 中 1fr ───────────────────────────────┬ 右 440px ──────────────┤
│ 情报源矩阵 220      │ KPI 条 120（5 块翻牌数字 + 环比）          │ Agent 编队 400        │
│ 群热度排行 300      │ 情报星图 470（力导向图 + 雷达扫描）         │ 作战日志 290（终端）   │
│ 消息构成 240        │ 头条情报轮播 180                            │ 推送回执与算力 170    │
├─────────────────────┴───────────────────────────────────────────┴───────────────────────┤
│ 底部 220：活跃热力 7×24 ｜ 风向词云 ｜ 上升信号（迷你折线 + z 值）                          │
└ 跑马灯 32px：最新情报标题和投递回执滚动                                                    ┘
```

纵向高度合计必须正好等于 1080，任何面板都不能出现滚动条（日志终端内部除外）。

### 4.1 顶栏
- 标题：`--font-display` 28px，字距 6px，青色到紫色渐变文字。每 8 秒做一次 120ms 的故障抖动（RGB 通道错位、clip-path 切片）。
- 平台灯：微信、QQ、飞书各一个小胶囊，颜色和动效随 health 变化：ok 时绿色呼吸灯，degraded 黄色，down 红色闪烁，disabled 或 unconfigured 灰色。悬停显示 detail 和 hint。
- 时钟用等宽字体，冒号每秒闪一次。倒计时显示 `下次出报 07:42:13`。
- 「立即出报」按钮：霓虹描边，悬停时内部有扫光；运行中显示能量进度条（按完成阶段数 / 12），再次点击可取消。

### 4.2 KPI 条（5 块）
今日消息、今日情报、活跃群（x/白名单数）、信噪比、上升信号。数值从 0 滚动到目标值，用时 1.2s，easeOutExpo。数值变化时数字闪一下高亮。下方显示环比徽标（▲ 绿 / ▼ 红）。底部放一条迷你 sparkline。

### 4.3 情报星图（视觉中心）
- ECharts `graph`（force 布局）：中心是三个平台枢纽节点（品牌色，大，带发光阴影），中间一圈是群节点，最外圈是话题节点（颜色取分类色）。边用渐变色加 `lineStyle.curveness`。
- 叠加层：
  - CSS 雷达：3 圈同心圆环，外加 1 条锥形渐变扫描臂，4 秒转一圈。
  - ECharts `lines` 系列在边上画移动的光点（`effect: {show:true, trailLength:.2, symbolSize:3}`，坐标取布局完成后的节点位置）。
  - 每 3 秒随机高亮一个话题节点（`dispatchAction` highlight 加 showTip）。
- 没有数据时显示"等待情报……"，雷达照常扫描。

### 4.4 头条情报轮播
横向卡片，每 6 秒切换一张。卡片内容：分类色条、标题（解码动效：乱码字符逐字还原，用时 600ms）、一句话价值、5 维评分小条、来源群胶囊、趋势徽标（NEW 青色 / 发酵中 琥珀色 / 重复 灰色）、风险标签（红色描边）。点击打开右侧抽屉：摘要、步骤、证据原文（引用块，带发言人和时间）、链接。

### 4.5 Agent 编队（右上）
2 列 × 4 行卡片，每个 Agent 一张：
`SCOUT 侦察兵` `SWEEPER 清道夫` `ANALYST 分析师` `DECODER 解码员` `STRATEGIST 参谋` `AUDITOR 审查官` `WRITER 主笔` `COURIER 通讯兵`
- 卡片内容：几何头像（SVG 六边形加图标）、代号、中文名、状态（待命 / 执行中 / 完成 / 告警）、当前任务一行（打字机效果）、一个指标，比如"已采集 1,204 条"。
- 执行中：边框旋转流光，头像外圈出现脉冲环，卡片轻微上浮。完成：显示绿色 ✓，状态亮一下。失败：红色闪烁两次。
- 卡片之间用 SVG 连线串成流水线，数据流光点沿线移动；运行到哪一段，哪一段变亮。

### 4.6 作战日志
黑底终端，等宽字体 12px。每行格式 `[08:00:13] DECODER ▸ 解析 群「水彩手绘研习社」块 3/12 → 候选 4 条`。新行用打字机效果逐字出现（每字 8ms，积压超过 20 行时直接整行显示）。按级别着色（info 青、warn 琥珀、error 红）。末尾有闪烁光标 `▍`。最多保留 200 行。

### 4.7 推送回执与算力
每个通道一行：图标、名称、最近结果（✓ 或 ✗）、时间。下面是 Token 计量：输入、输出 token 和费用（元）用滚动数字显示，加一个环形进度表示本次预算占用。模型名和"云端同意"状态也放这里；未同意时显示"离线模式"徽标。

### 4.8 底部三块
- 7×24 热力：ECharts heatmap。颜色从深蓝经青色到品红；悬停显示具体数量。
- 风向词云：`echarts-wordcloud`。上升词用品红并带光晕，新词用青色，其余用灰蓝；每 10 秒重新排布一次（带过渡）。
- 上升信号：最多 6 行。每行是关键词、今日次数、z 值徽标、7 日迷你折线、来源群。按 z 值降序。

### 4.9 跑马灯
匀速滚动，鼠标悬停时暂停。每条前面加分类色点。

## 5. 其它页面（共用外壳）

左侧 64px 竖向导航，图标加悬停提示，激活项有一道发光竖条。页面顶部是标题和面包屑。背景层沿用大屏，但降低粒子密度。页面内容可以滚动，宽度自适应，最小 1280。

| 路由 | 页面 | 主要内容 |
|---|---|---|
| `/` | 作战大屏 | 见 §4 |
| `/reports` | 情报档案 | 左侧时间轴列表（日期、头条数、投递状态），右侧阅读器渲染 `full_md`（深色排版，证据引用块，来源胶囊）；导出 md/html/json；重新投递 |
| `/sources` | 情报源 | 三个平台标签页：适配器选择、按 config_schema 动态生成配置表单、测试连接、健康状态与修复建议；群表格（搜索、白名单开关、批量操作、权重滑块、标签、24h/7d 消息数）；"刷新群列表"；导入区（拖入文件或粘贴文本） |
| `/schedules` | 调度中心 | 任务卡片：cron 预设（每天 08:00、每天 12:00 和 20:00、工作日 09:00、自定义）、人话解释、下次运行时间；平台和群范围、通道多选、TOP N、仅预览；运行历史表，点开显示阶段时间线和日志 |
| `/channels` | 推送通道 | 新增通道（类型卡片选择 → 按 schema 生成表单）、启用开关、发送测试、最近结果 |
| `/agents` | 智能体 | 模型提供方选择与配置、测试调用、云端同意开关（附清楚的说明）、并发和预算；兴趣画像（标签输入）、屏蔽词、分类权重；提示词编辑器（等宽字体，保存前确认） |
| `/system` | 系统 | 体检清单（doctor）、日志查看（筛选级别）、隐私（脱敏开关、保留天数、实时预览）、演示数据（写入 / 清除）、特效强度（高 / 中 / 低 / 关） |

## 6. 技术要求

- Vue 3 + Vite + TypeScript + vue-router + ECharts 5（加 `echarts-wordcloud`），用 markdown-it（`html:false`）和 DOMPurify 渲染 Markdown。不引入大型 UI 组件库，表单控件自己写，统一 HUD 风格。
- 目录：`web/src/{api,mock,components,views,styles,composables,stores}`。状态管理用轻量的 composable 和 reactive store，不必引入 pinia。
- `src/api/client.ts`：先取 session token，自动加请求头；把 SSE 封装成可订阅的事件源，带重连。
- `src/mock/`：`VITE_MOCK=1` 或后端连不上时启用。生成逼真的中文数据（群名、话题、日志），并模拟一次完整运行，让 12 个阶段依次推进、日志滚动，用来本地看效果。
- 大屏缩放：`useScreenScale` 按 `min(innerWidth/1920, innerHeight/1080)` 做 transform scale。
- 性能：动画只用 transform 和 opacity；ECharts 在 resize 时防抖，卸载时 dispose；粒子数随特效强度变化（高 160、中 100、低 40、关 0）。
- 无障碍：遵守 `prefers-reduced-motion`；特效强度为"关"时停止所有循环动画。
- 构建产物在 `web/dist`，由后端托管。Vite `base: '/'`；开发服务器端口 5180，`/api` 代理到 `http://127.0.0.1:8765`（`changeOrigin: true`，SSE 不缓冲）。
