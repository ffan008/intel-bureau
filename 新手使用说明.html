个人情报局 · 新手使用说明

这份说明写给第一次用、不懂代码的人。照着做，10 分钟内能在自己电脑上看到完整的作战大屏。

它是什么

每天在你设定的时间，自动读取你自己加入白名单的群聊，把里面有价值的信息整理成一份「每日风向标」：

  • 多篇专题知识文章（带群里的原话、提示词原文、联网查到的补充资料和来源）
  • 资源库（GitHub 项目、网盘链接和提取码、公众号文章……）
  • 知识库（同一个话题跨天自动合并更新，可以搜索）
  • 图片里的文字、群里发的文档内容，也会被提炼进去

整个程序只在你自己的电脑上运行，不会上传你的聊天记录。

一、你需要准备什么

需要 说明
Windows 10 / 11，或苹果电脑（macOS 12 以上） 苹果电脑用 .command 版本，见下面「苹果电脑怎么装」
能上网 第一次安装要下载 Python 依赖，大约 100 MB（微信、QQ、飞书的接入工具已经随包带好，不用再下）
约 1.5 GB 空闲磁盘 压缩包约 460 MB，解压加安装后会更大
Python 3.12 以上 没有的话，安装步骤里会教你装，见下一节
（可选）一个 DeepSeek 账号 想让 AI 帮你写专题文章才需要，不配也能用，见第五节

不需要装 Node.js：前端已经做好了，飞书的 lark-cli 也是随包带的现成程序。

苹果电脑怎么装

双击 「一键安装并启动.command」，后面的流程和 Windows 一样：自动装依赖、写入演示数据、打开大屏。 第一次打开如果提示「无法验证开发者」，在文件上右键 →「打开」即可。

注意：飞书、微信在苹果电脑上都能直连。微信要装 WeChatDataAnalysis 的 mac 版（-mac-arm64.dmg），打开它并解密账号，再到「情报源 → 微信 → 测试连接」； 它的 API Token 留空就行，程序会自己读。QQ 的采集工具是 Windows 程序，Mac 上用 「导入聊天记录」（把 JSON / CSV / txt 拖进「情报源」的导入区）。完整说明见 docs/SETUP_MAC.md。

二、安装（只做一次）

第 1 步：解压

把收到的压缩包解压到一个简单的位置，比如 D:\情报局 或 D:\IntelBureau。

  • 路径里尽量不要有空格和特殊符号。
  • 不要放在「桌面」「下载」「OneDrive」「Program Files」里，容易因为权限或同步出问题。

第 2 步：装 Python 3.12（已经装过就跳过）

  1. 打开 https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe 下载安装程序。
  2. 双击运行，第一个界面最下面一定要勾选「Add python.exe to PATH」，然后点 Install Now。
  3. 装完点 Close。

版本要求是 3.12。装了 3.13 或更新版本的话，请另外再装一个 3.12。

第 3 步：双击「一键安装并启动.bat」

  • 会弹出一个黑色窗口，自动完成：检查 Python → 下载并安装依赖 → 写入一份演示数据 → 启动。
  • 第一次大约 2~5 分钟，期间会显示英文进度，不用管，也不要关窗口。
  • 完成后会自动弹出浏览器窗口，进入作战大屏。

如果 Windows 弹出「已保护你的电脑」（SmartScreen）：点「更多信息」→「仍要运行」。 如果黑窗口一闪就没了：右键「一键安装并启动.bat」→ 以普通方式再运行一次，并留意窗口里的红字提示。

以后怎么打开

再次双击「启动情报局.bat」就行（比一键安装快很多）。苹果电脑双击「启动情报局.command」。

  • 黑色窗口要一直开着，关掉它，工作台就停了。
  • 想让它开机自动在后台跑：在文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」，输入 powershell -ExecutionPolicy Bypass -File scripts\install-autostart.ps1 回车。取消的话把 install 换成 uninstall。
  • 苹果电脑：双击「开机自启设置.command」，选 1 设置自启，选 2 取消。

三、先看一遍演示数据

第一次打开时，里面的群、对话、人名全是虚构的演示数据，用来让你熟悉界面。左侧是导航：

页面 用来做什么
作战大屏 一屏看全局：各平台状态、群热度、情报星图、头条、实时日志。点右上角「立即出报」能看到整个流水线跑一遍
情报档案 每一份「每日风向标」。左边选日期，右边用标签页切换：今日总览、专题文章、资源库、提示词原文、方法与 SOP、工具与模型、收益与数据、风险与踩坑、金句、图片与文档、分群摘要、快讯
知识库 所有专题文章的长期沉淀，可搜索、按分类和标签筛选，能看每篇的历史版本
情报源 连接微信 / QQ / 飞书，勾选要关注的群（白名单），或导入聊天记录文件
调度中心 设置每天几点自动出报
推送通道 设置报告发到哪里（飞书、微信、邮箱等）
智能体 选择 AI 模型、云端同意、兴趣词、提示词
系统 体检；写入或清除演示数据

用自己的数据之前：到「系统」页点「清除演示数据」。它只删演示的内容，不影响你之后接入的真实数据。

四、接入你自己的群（三选一，从最简单的开始）

方法 A：导入聊天记录文件（最简单，推荐先试）

不需要登录任何账号。把导出的聊天记录文件（JSON、CSV，或从微信里复制出来的文字）拖进「情报源」页面右上角的导入区即可，或放进 data\inbox\微信 这样的文件夹。支持哪些格式，见 docs\SETUP_WECHAT.md 里的「导入聊天记录」一节。

方法 B：直接读取微信 / QQ / 飞书（可以每天自动更新）

这一步稍微复杂，每个平台一份图文步骤，照着做：

平台 文档 一句话说明
微信 docs\SETUP_WECHAT.md 读取电脑上微信的本地聊天记录（只读，不登录、不发消息）。需要电脑登录着微信 PC 版
QQ docs\SETUP_QQ.md 通过 NapCat 读取。强烈建议用一个小号，避免主号被平台风控
飞书 docs\SETUP_FEISHU.md 用飞书官方命令行工具，在浏览器里点一次授权

三个接入工具已经随包带好了，不用再去网上下载，放在 third_party\tools 里。想接哪个平台，就双击根目录的「安装接入工具.bat」，在菜单里选：

菜单 工具 它会帮你做什么
1 微信 WeChatDataAnalysis 先校验安装程序没有损坏，再打开它的安装向导，一路下一步即可（约 380 MB）
2 QQ NapCatQQ 校验并解压，然后告诉你下一步怎么登录小号、怎么设置
3 飞书 lark-cli 确认它能运行，然后带你完成「配置应用」和「授权」两步
4 三个都准备 依次做上面三件事

只用「方法 A」导入文件的话，这一步可以完全跳过。

这三个都是第三方开源软件，版权和许可归原作者所有，许可证全文见根目录的 THIRD_PARTY_NOTICES.md。NapCatQQ 的许可证禁止商业使用，请仅用于个人学习和朋友间使用。

接好之后：「情报源」页 → 点「刷新群列表」→ 只把你想关注的群打开白名单开关。没打开的群不会被读取，也不会存储。

请只读取你自己账号里的群聊。 使用前请确认符合各平台的使用条款和相关法律，并尊重群友隐私。

然后：设置每天几点出报

「调度中心」里默认有一个「晨报」，每天 08:00 运行。可以改时间、选平台、选推送到哪里。点「立即运行」可以马上跑一次试试。

定时任务要求电脑开着、工作台在运行。电脑关机错过的任务，下次启动时会自动补跑一次。

五、让 AI 帮你写专题文章（可选，但效果好很多）

不配 AI 也能用：这时用的是离线规则，只会把群里的原话摘录出来，没有"扩展研究"。想要完整的专题文章，需要一个 AI 模型：

  1. 到 https://platform.deepseek.com/ 注册，充值几块钱，在「API Keys」里创建一个 Key 并复制（以 sk- 开头）。
  2. 回到工作台 →「智能体」页：
    • 模型提供方选「OpenAI 兼容接口」，预设选「DeepSeek」。
    • 把 Key 粘贴到「API Key」，点「测试调用」，看到成功就对了，再点「保存」。
  3. 在同一页打开「云端同意」开关。
    • 这一步很重要：打开后，白名单群里的聊天内容才会发给 DeepSeek 的服务器去处理；不打开的话，系统会一直用离线规则，不会外发。
    • 手机号、邮箱、证件号、银行卡号等会在发送前自动打码。
  4. 建议把「单次费用上限」设成一个数（比如 5 元），超过后自动改用离线规则，不会花超。

大概花多少钱？ 取决于你关注多少个群、每天消息多不多。参考：关注约 60 个活跃群，一次完整运行大约 1~2 元。关注几个群的话要少得多。具体以 DeepSeek 官网价格为准。

六、隐私与安全，请务必看

  • 聊天记录只存在你这台电脑上（data 文件夹）。只有你打开「云端同意」并配置了 AI，才会把白名单群的内容发给你选的 AI 服务商。
  • API Key、推送口令保存在 config\secrets.yaml，不要发给别人。
  • 如果你要把这个文件夹再转发给别人：先删掉 data 文件夹和 config\secrets.yaml、config\settings.yaml，里面有你的聊天记录和密钥。
  • 工作台只监听本机地址（127.0.0.1），同一个 Wi-Fi 下的其他人访问不到。
  • 程序只读聊天记录，不会替你发消息、不会改动你的微信 / QQ / 飞书。

七、常见问题

双击 bat 后窗口一闪就没了。 先确认已经解压（不要在压缩包里直接双击）。再试：在文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」，输入 .\一键安装并启动.bat 回车，窗口不会自动关闭，能看到错误信息。

提示「没有找到 Python 3.12」。 按第二节第 2 步安装，一定要勾选 Add python.exe to PATH，装完关掉窗口重来。如果你的电脑装过 Python 但还是找不到，可能装的是别的版本，另外装一个 3.12 即可。

提示「无法加载文件……因为在此系统上禁止运行脚本」。 用我们提供的 bat 文件启动不会遇到这个问题。如果你是手动输入命令，请带上 -ExecutionPolicy Bypass。

安装卡住、下载很慢或失败。 这一步要从网上下载依赖，换个网络，或者开关一下代理，然后重新双击「一键安装并启动.bat」，会接着装。

浏览器页面打不开 / 显示「服务已启动」提示页。 确认黑色窗口还开着。手动在浏览器地址栏输入 http://127.0.0.1:8765 试试。

端口被占用，提示 8765。 说明已经有一个工作台在运行了，直接打开 http://127.0.0.1:8765 即可；或者先关掉旧的黑色窗口。

点了「安装接入工具.bat」，提示校验不一致。 说明压缩包在传输中损坏了。请让对方重新发一次完整的压缩包，不要用「已损坏」的文件。

报告里都是"程序从原文摘录"，不够流畅。 说明还在用离线规则。按第五节配置 AI 并打开「云端同意」。

怎么停止？ 关掉那个黑色窗口。

怎么升级？ 把新版本解压到新文件夹，再把旧文件夹里的 data 和 config 两个文件夹复制过去覆盖即可。

我想看某个功能的详细说明。 文件夹里的 README.md 是总览，docs 文件夹里有各平台接入、推送通道、接口等详细文档。
